ShopKart E-Commerce MIS Dashboard

An automated MIS dashboard built in Excel to analyze e-commerce sales data, providing management-level reporting through pivot tables, KPI cards, and interactive slicers.

📊 Overview
This project simulates a real-world MIS reporting task for an e-commerce business (ShopKart). It uses a sales dataset of 250+ rows to generate automated, interactive reports that help track revenue, orders, and ratings without manual data entry.

🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- VLOOKUP, XLOOKUP, INDEX-MATCH, FILTER
- Report Connections (Slicers)

✨ Features
- Fully automated MIS dashboard with pivot tables and KPI cards (Total Revenue, Orders, Avg Rating)
- Interactive slicers connected via Report Connections for dynamic filtering
- VLOOKUP, XLOOKUP, INDEX-MATCH, and FILTER functions used to automate data retrieval and reduce manual lookup time
- Category-wise, city-wise, and quarter-wise breakdowns using 8 pivot tables and 7 charts
- Enables instant, management-level reporting for business decisions

📁 Dataset
ShopKart Sales Dataset (250+ rows)

📌 Key Skills Demonstrated
Data Accuracy, Record Management, Process Documentation, Deadline Management
